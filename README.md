# TaskHub

Task Management API built with FastAPI.

## Project Description

TaskHub is a task management system that allows users to manage workspaces, projects, tasks, labels, and comments.

## Tech Stack

- Python
- FastAPI
- Pydantic v2
- SQLAlchemy 2.x Async
- Alembic
- PostgreSQL
- Redis
- Docker

## Project Status

Currently under development as part of the Python Tech Stack - FastAPI module.
